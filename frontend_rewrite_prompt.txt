## Stack

Vite + React + TypeScript, in `webui/frontend/`. Use:
- **TanStack Query** for all server state — replaces every manual `setInterval` poll of
  `/api/state`, `/api/images`, `/api/meta`, `/api/films`. Mutations invalidate queries.
- **Tailwind v4 + Radix primitives** (shadcn/ui is fine). Port the existing dark palette
  (the `:root` CSS variables in `app.py`) into the Tailwind theme — keep the look, sharpen it.
- **Zustand** for client-only state: selected job, lightbox index, breed-selection pair, active tab.
- **`@tanstack/react-virtual`** for the gallery, replacing the current 200-item pagination entirely.

## The core requirement: a declarative param schema

The current sidebar has ~45 inputs whose visibility is toggled via CSS classes (`.genonly`, `.genimg`,
`.coh`, `.ngen`, `#sdxlModelWrap`). Replace that with a data-driven schema — one entry per knob, e.g.:

```ts
{ id: "coherence", label: "Coherence λ", type: "number", step: 0.1, placeholder: "0.5",
  group: "sampler", when: { action: ["generate"], sampler: ["blend"] },
  hint: "0 ≡ diagonal, 1 ≡ pca" }
```

Rendering, form state, and the `/api/run` payload all derive from this one array. Adding a knob must mean
adding one object and nothing else. Preserve every existing control, default, placeholder, and tooltip —
cross-check against `build_argv` and `cli_args.py` so no knob is silently dropped.
